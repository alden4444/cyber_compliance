The Zero-Payload Data Contract

Robotics companies handle sensitive proprietary hardware, spatial navigation maps, and training data. Roam enforces strict zero-payload telemetry at the architectural level.

check_circle Security Metadata We Collect
  • done Firewall State: Verification that UFW, firewalld, or iptables default drop rules are active.
  • done Listening Sockets: TCP/UDP port numbers bound to local vs public interfaces.
  • done Disk Encryption: Verification of LUKS, FileVault, or BitLocker block encryption.
  • done Patch SLA: Package currency and operating system kernel version hashes.
block Data Roam Never Touches
  • close Camera & Vision Streams: Zero video, raw sensor frames, or image captures.
  • close Spatial Maps: Zero LiDAR point clouds, SLAM graphs, or occupancy grids.
  • close Control Logic: Zero motor trajectory commands, joint kinematics, or actuator states.
  • close Customer Source Code: Zero code inspection, proprietary models, or neural weights.
